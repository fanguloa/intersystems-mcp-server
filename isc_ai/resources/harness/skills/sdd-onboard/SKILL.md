## Activation Contract
Guide a user interactively through one small, safe, real change.

## Hard Rules
- Ask for artifact-store mode before writes and pause after proposal review.
- Keep narration brief and use production-quality artifacts and code.
- Stop on failed tests, unclear design, or unsafe scope.

## Execution Steps
Find a suitable improvement, then narrate explore, propose, spec, design, tasks,
apply, verify, and archive using the installed phase skills.

## Output Contract
Return the selected change, artifacts, code/test evidence, lessons, and the standard envelope.
