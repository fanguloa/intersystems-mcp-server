# Runtime Compatibility

System permissions, user-approved scope, and project policy bound all work.
Instruction files do not install tools or grant access. The model-role template
is future configurator input only: provider/model IDs remain unselected,
availability is unverified, and `runtime_applied` is false. Inspect the actual
agent/task schema before routing. If no selector or delegation tool exists,
report that limitation and do not simulate success. Restart clients after
configuration or harness changes because active sessions can retain old text.
