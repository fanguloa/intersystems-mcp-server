# Verification Report Format

Report change and mode; task completeness; exact build/test commands and results;
coverage when available; a requirement/scenario/test matrix with COMPLIANT,
FAILING, UNTESTED, or PARTIAL; static correctness; design coherence; issues by
CRITICAL, WARNING, and SUGGESTION; and verdict PASS, PASS WITH WARNINGS, or FAIL.
Strict TDD reports also include cycle evidence, assertion quality, test layers,
and changed-file coverage.
