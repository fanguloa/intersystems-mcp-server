# OpenSpec Convention

Use `openspec/config.yaml`, `openspec/specs/{domain}/spec.md`, and
`openspec/changes/{change}/` containing `proposal.md`, `design.md`, `tasks.md`,
`verify-report.md`, and `specs/{domain}/spec.md`. State lives in `state.yaml`.
Archive verified changes to `openspec/changes/archive/YYYY-MM-DD-{change}/`.

Read existing files before updating. Preserve requirements not named by a
delta. Never modify archived changes.
